## Card Match Game


- Built from scratch using Unity 2021 LTS
- Card flipping & matching logic with smooth animations
- Scalable layouts: Supports multiple grid sizes 
- Save/load system: Game progress is persisted across sessions
- Scoring system 
- Sound effects: Includes sounds for flip, match, mismatch, etc

Tools & Tech

- Unity 2021 LTS
- C#
- Git 
- PlayerPrefs & json for save/load system
- Dotween for animation
